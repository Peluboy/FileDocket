One click, or leave Auto-Organize on and new downloads land in the right folder on their own.

Setup

Three steps.

Download the DMG or use Homebrew. First launch on current macOS may need Open Anyway in System Settings.

01

Install

Download the DMG, or run the Homebrew command below. Drag FileDocket into Applications. Both paths are supported.

02

Open the menu

Click the FileDocket icon in the menu bar, then Organize Now.

03

Done

Files are sorted. The menu shows what moved. Undo if you need to.

export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH" && brew install --cask peluboy/tap/filedocket

Homebrew and the DMG are equal options. If brew is missing, open a new Terminal after installing Homebrew, or download the DMG. Already tapped peluboy/filedocket? Run brew untap peluboy/filedocket first.

FAQ

Questions.

The short version: it moves files on your Mac, the code is public, and first launch may need Open Anyway in System Settings.

Is FileDocket safe?

It only moves files. It does not delete them. Every move is logged and can be undone. The source is on GitHub.

What about the unidentified developer warning?

On macOS Sequoia and later, open FileDocket once and click Done (not Move to Trash). Then System Settings → Privacy & Security → Security → Open Anyway. That button only appears after a blocked open. Control-click → Open no longer works. If the button never shows, run xattr -cr /Applications/FileDocket.app and open the app again.

Which folders does it organize?

Downloads by default. You can add more in the app. Free includes one extra folder. Pro has no limit.

Can I install with Homebrew?

Yes. One command: brew install --cask peluboy/tap/filedocket. Homebrew 6 requires trusting third-party taps; the fully-qualified name does that. If you already tapped peluboy/filedocket, run brew untap peluboy/filedocket first. If you just installed Homebrew, prepend export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH" &&.

brew says untrusted tap or the cask exists in multiple taps

Homebrew 6 will not load a third-party tap until you trust it. Use the fully-qualified install command above. If you tapped both peluboy/tap and peluboy/filedocket, they are the same cask twice. Run brew untap peluboy/filedocket, then brew install --cask peluboy/tap/filedocket.

It says brew: command not found

Homebrew is installed, but this Terminal session cannot see it yet. Open a new Terminal window, or run eval "$(/opt/homebrew/bin/brew shellenv)" on Apple Silicon (/usr/local/bin/brew on Intel), then the install command. You can also skip Homebrew and download the DMG.

Does anything leave my Mac?

No analytics, no accounts for the free app. Organizing runs locally. Pro checkout goes through Lemon Squeezy.
