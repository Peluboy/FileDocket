FAQ

Is FileDocket safe?

Yes. FileDocket only moves files, it never deletes anything. Every move is logged and undoable. The code is open source.

What about the "unidentified developer" warning?

Since we're a small indie app (not on the Mac App Store), macOS shows a Gatekeeper warning on first launch. Just right-click the app → Open → click "Open." You only do this once.

What folders does it organize?

Downloads by default. You can add extra folders in the app (Pro: unlimited, Free: 1 extra folder).

Can I install via Homebrew?

Yes! brew tap peluboy/fileflow && brew install --cask fileflow

What's the difference between Free and Pro?

Free includes the core organizer, auto-organize, undo, and 3 custom rules. Pro adds the Duplicate Finder, Deep Scan, unlimited rules/folders, and archive old files for a one-time $8 payment.
