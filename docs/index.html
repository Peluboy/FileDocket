Product

Sort files. Keep them.

Downloads by default. Desktop, Documents, or any folder you add. A file organizer with categories for Images, Documents, Audio, Video, Archives, Code, Fonts, and Installers.

Auto-categorize

One click, or leave Auto-Organize on. New files in watched folders land in the right place on their own.

Always undoable

Every move is logged. Put a file back where it was, or browse history.

Background, not a daemon

Auto-Organize uses launchd on Mac and Task Scheduler on Windows. Nothing sits in RAM waiting for the next file.

Custom rules

Match a name or an extension. Send invoices to Finance, ISOs to a disk folder.

Never deletes

FileDocket moves files. It does not trash them, upload them, or read their contents off-device.

Any folder you add

Downloads is the start, not the limit. Add Desktop, Documents, or a work dump. Free includes one extra. Pro has no cap.

FAQ

Questions.

The short version: it moves files on your computer, the code is public, and first launch may need a one-time OS prompt (Gatekeeper on Mac, SmartScreen on Windows).

Is FileDocket a file organizer for Mac and Windows?

Yes. FileDocket is a free file organizer for the Downloads folder, Desktop, and any folder you add. It lives in the macOS menu bar and the Windows tray. It only moves files. Every move can be undone.

Is FileDocket safe?

It only moves files. It does not delete them. Every move is logged and can be undone. The source is on GitHub.

What about the unidentified developer warning on Mac?

On macOS Sequoia and later, open FileDocket once and click Done (not Move to Trash). Then System Settings → Privacy & Security → Security → Open Anyway. That button only appears after a blocked open. Control-click → Open no longer works. If the button never shows, run xattr -cr /Applications/FileDocket.app and open the app again.

Windows says SmartScreen protected my PC

The Windows installer is not Microsoft-signed yet. Click More info, then Run anyway. That is a one-time prompt. After that, FileDocket is in the notification area (hidden icons if you do not see it).

Which folders does it organize?

Downloads by default — it is a Downloads organizer first. Add Desktop, Documents, or any other folder in the app. Free includes one extra. Pro has no limit.

Can I install with Homebrew?

On macOS only. You do not need Homebrew. The one-line installer checks for it: curl -fsSL https://peluboy.github.io/FileDocket/install.sh | bash. If brew is present, it installs the cask. If not, it uses the DMG. Homebrew-only: export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH" && brew install --cask peluboy/tap/filedocket. Windows users should download the Setup exe.

brew says untrusted tap or the cask exists in multiple taps

Homebrew 6 will not load a third-party tap until you trust it. Use the one-line installer, or brew install --cask peluboy/tap/filedocket. If you tapped both peluboy/tap and peluboy/filedocket, they are the same cask twice. Run brew untap peluboy/filedocket, then install again.

It says brew: command not found

That command is macOS only. If you are on Windows, download the Setup exe. On a Mac, you do not need Homebrew: use the one-line installer (it falls back to the DMG) or download the DMG. If you ran brew install yourself, either Homebrew is not installed, or this Terminal session cannot see it yet. Open a new Terminal window, or run eval "$(/opt/homebrew/bin/brew shellenv)" on Apple Silicon (/usr/local/bin/brew on Intel).

How do I uninstall?

macOS: curl -fsSL https://peluboy.github.io/FileDocket/uninstall.sh | bash, or brew uninstall --cask peluboy/tap/filedocket, or drag FileDocket from Applications to Trash. Windows: Settings → Apps → FileDocket → Uninstall. Organized files are not deleted. Add brew --zap only on Macs that are not a FileDocket source checkout.

Does anything leave my computer?

The FileDocket app does not send analytics. This website can measure visits and download clicks so we can see which installer people use. Pro payments are tracked only in Lemon Squeezy.
